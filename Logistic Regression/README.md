# Logistic Regression From Scratch in R
This repository contains a <b> Logistic Regression </b> implementation built entriely <b> from scratch </b> using R = no `glm()` or other machine learning libraries.

## Overview
This project demonstrates:
- Implementing <b> Logistic Regression </b> using gradient descent
- Understanding the math of the sigmoid function and cross-entropy loss
- Generating synthetic data and training a binary classifier
- Visualizing the <b> decision boundary </b> using `ggplot2`

## Files Included
- `logistic_regression_from_scratch.R`: Core implementation of logistic regression
- `README.md`: This readme file

## Example Output
Your script will:
- Print the model's accuracy on the synthetic data
- Plot the training data with the learned decision boundary
