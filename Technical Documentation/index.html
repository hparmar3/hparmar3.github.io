HTML Basics

HTML stands for HyperText Markup Language.

It is used to structure content on the web.

An HTML document is made up of elements.

Elements are represented by tags.

Tags can be paired (opening and closing) or unpaired.

<!DOCTYPE hmtl>

This declaration defines the document types.

<hmtl></html>

The root element of an HTML page.

CSS Fundamentals

CSS stands for Cascading Style Sheets.

It is used for style HTML documents.

CSS describes how HTML elements are to be displayed.

CSS can be applied in three ways: inline, internal, and external.

CSS rules are composed of selectors and declarations.

selector { property: value; }

This is the basic syntax of a CSS rule.

body { font-family: Arial, sans-serif; }

This rule sets the font family for the body element.

JavaScript Overview

JavaScript is a versatile programming language.

It is used to create interactive effects within web browsers.

JavaScript can update and change both HTML and CSS.

It can also calculate, manipulate, and validate data.

JavaScript is executed on the client side by the browser.

console.log('Hello, world!');

This lines prints "Hello, world" to the console.

document.getElementById('main-doc');

This line accesses an element by its ID.
