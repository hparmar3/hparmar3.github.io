# Technical Documentation Page
A responsive, <b> Technical Documentation Page </b> built with HTML and CSS. It is structured into sections covering foundational web development topics: HTML, CSS, JavaScript, and development tools.

## Live Preview
You can lauch the page locally or use Live Server:
```bash
npm install -g live-server
live-server
```

## Features
- <b> Fixed navigation bar </b> with section links
- <b> Anchor-based scrolling </b>
- <b> Semantic HTML </b> with sections and headers
- <b> Responsive layout </b> using external CSS
- <b> Inline code snippets </b> and unordered lists for clarity

## Sections Covered
### 1. Introduction
- overview of web development
- use of tools like `live-server`

### 2. HTML Basics
- elements, tags, and attributes
- semantics and structure

### 3. CSS Fundamentals
- styling approaches (inline, internal, external)
- syntax, selectors, and declarations

### 4. JavaScript Overview
- language basics
- DOM manipulation and event handling

### 5. Web Development Tools
- version control with Git
- editors and IDEs like VS Code
